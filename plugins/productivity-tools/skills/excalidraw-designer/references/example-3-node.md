## What to notice

- Each shape's `boundElements` lists both its text label and its connected arrows.
- Each text `containerId` points back to its parent shape.
- Each arrow's `startBinding`/`endBinding` reference the shapes it connects.
- All `id` and `seed` values are unique; arrow `points` start with `[0, 0]`.
