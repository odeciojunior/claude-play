# Report Template

Structure for the cited Markdown report the deep-researcher skill writes to `docs/reports/`. Keep the section order; add as many numbered theme sections as the research needs. The "What's New" note is optional.

```markdown
# <Report Title>

**<Subtitle describing scope or context>**

**<Month Year>**

> **What's New** (optional): <One-paragraph summary of what this report covers and why it matters now.>

> **Note**: <Contextual notes, terminology clarifications, or domain-specific definitions.>

---

[Key findings in 2-3 paragraphs. State the core question, the answer, and the confidence level.]

| Date | <YYYY-MM-DD> |
| Status | <Complete / Partial> |
| Sources consulted | <count> |
| Confidence | <High / Medium / Low> |

### Key Findings — Overview

| Finding | Confidence | Impact |
|---------|------------|--------|
| <finding 1> | <High/Medium/Low> | <description> |
```
